# TabscrAIp Quick Start Guide

Get up and running with TabscrAIp in 5 minutes!

## 1. Install (2 minutes)

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `tabscrAIp` folder
5. Pin the extension icon to your toolbar

## 2. Configure (1 minute)

1. Click the TabscrAIp icon
2. Enter your Claude API key from [Anthropic](https://console.anthropic.com/)
3. Click **Save**

## 3. Test (2 minutes)

1. Open `examples/sample-page.html` in Chrome
2. Click the TabscrAIp icon
3. Click **Scrape Current Page**
4. Watch the magic happen! ✨

## What You'll See

- A table with product data
- Sortable columns (click headers)
- Drill-down buttons
- Export options

## Try These Features

### Sorting
Click any column header to sort the data

### Grouping  
If enabled, click group headers to expand/collapse

### Drill-Down
Click "Drill Down" to fetch more data from URLs

### Export
Click "Export CSV" or "Export JSON" to download data
